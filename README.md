## About

This is a freelance project: a responsive website for Ani & Aji Tour & Travels, a travel business in Munnar. It is built with React and Vite and hosted on Vercel.

## Project Status

| Stage       | Status      |
| ----------- | ----------- |
| Design      | Complete    |

The live link shows the current design. More features are being added.

## What the Design Covers

- Tour packages for adventure, hill station, chill vibes, party night, and campfire trips.
- Kolukkumalai jeep safari.
- Resorts and cab booking.
- Call and WhatsApp options to ask for a quote.
- A responsive layout for phones, tablets, and desktops.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/mathan-ponraj/ani-aji-travels.git
```

Go to the project folder:

```bash
cd ani-aji-travels
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
